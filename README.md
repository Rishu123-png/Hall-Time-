# HALLTIME

Made by Rishu Jaswar.

Fullscreen digital clock for examination halls. Open it on the projector or smart board instead of searching “digital clock”.

## For the invigilator

1. Open the page and press **F** (or Fullscreen) so students do not see the browser.
2. For a plain clock, leave it. The controls hide themselves.
3. For a paper, press **Start exam**.
   - **1 hour test** — starts when you press begin.
   - **3 hour paper** — 15 minutes reading, then 3 hours.
   - **CBSE morning** — reading 10:15, writing 10:30 to 1:30. Set this up before students enter. The board waits.
4. Extra time is for a room that has been allowed extra minutes. Use another window for a room with a different allowance.
5. **+5 min** adds time during the paper. **Pause** freezes the countdown if there is a disturbance. The wall clock keeps running.
6. Bells play on this computer: long bell at the start and the end, short bell every hour, at 15 minutes, and at 5 minutes. A banner still shows if the speakers are off.
7. **Daylight** theme if the hall is bright. **Blackboard** for a dark room or projector. **LED** digits are the classic board look; plain digits read better from the back.

This clock uses the computer’s clock. Match it to a phone before the exam.

## Language

English or हिन्दी, from Display. Turn on “English and Hindi together” if the hall needs both.

## Share a link

In Display, copy **Share this board**. The school name and theme are in the link:

`https://your-site.example/?school=Your%20School&theme=daylight&lang=hi`

## Put it online

Upload this folder to any static host (Cloudflare Pages, Netlify, GitHub Pages, or the school server). No build step. After the page has loaded once, the clock keeps running if the internet drops.

## Keys

F fullscreen · E exam · D display · Space pause · + add 5 minutes · T theme · L language · M mute · Esc close
